# 챗봇 아이콘

- 왼쪽 아이콘 바 맨 아래에 이름 ‘챗봇’을 가진 버튼을 둔다(아이콘 + 라벨). 패널은 탑재 패널과 같은 자리에서 밀려 나오고, 하나가 열리면 다른 하나는 닫힌다. 클릭으로 닫힌 패널을 열고 다시 클릭하거나 닫기 버튼으로 닫는다. 초기 상태는 닫힘이다.
- 1차 범위는 버튼과 패널이다. 실제 대화, 모델, API 연동은 후속 작업으로 두고 패널에서 연결 준비 상태를 표시한다.
- 먼저 `Authoring/Dashboard.uxml`, `Runtime/Dashboard/ErectionPanelView.cs`를 확인한다. 패널 상태와 이벤트는 필요 시 `Runtime/Dashboard/DashboardChatView.cs`에서 관리한다.
- 확인 기준은 아이콘 바 맨 아래 위치, 키보드 접근, 반복 열기·닫기, 패널 안에서의 클릭이 카메라로 전달되지 않는 것이다.
