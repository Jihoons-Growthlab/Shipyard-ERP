| 메뉴 | 조회·처리 | 주요 규칙 |

| 계획 › 중일정 · 선체 | 탑재 계획·선후행, 블록 적치·구성, 일정 제안, 크레인 부하, 준비 현황 | 탑재 일정 제안에 선행 블록·도크 예약·장비 능력 반영 |

| 관리 › 설계 도면 | 도면 리비전·설계 변경, EBOM 리비전·품목, 호선·블록 형상 | 발행 EBOM의 편집 제한 |
| 계획 › 제조 BOM · MRP | MBOM 공정·투입품, 발행 전 비교, 자재 부족과 근거, 설계 변경 조정 | MBOM 발행 시 자재 소요 반영. 후속 문서와 적용 리비전 추적 |
| 실행 › 구매·입고 / 자재 출고 / 강재 추적 | 구매요청, 발주, 입고·검수, 출고, 수불부, 강재 로트·히트번호 | 블록에서 출고 로트와 입고 증빙까지 추적 |
| 실행 › 작업지시·실적 / 블록 조립·공수 / 의장품 | 주간·일일 지시, 작업 실적, 조립 단계별 공수, 의장품 진행 | 일일 지시를 주간 지시에 연결. 단계별 실적과 진척 기록 |
| 실행 › 블록 이동 | 블록 위치, 이동 시작·확정, 장비 관측 | 이동 확정 시 블록 위치 갱신. 관측 시각·좌표·하중은 별도 기록 |
| 진척·품질 | 공정 계획·실적, 작업 준비, 물량·공수, ITP·입회검사·NCR·펀치 | 작업과 검사 이력 기록, 계획 공수와 투입 공수 비교 |
| 관리 › 기준정보 / 형상·배치 / 사용자·권한 | 호선·블록·장비·자재, 시설 좌표, 도크 선체 배치, 계정·그룹·감사 이력 | 메뉴별 조회·등록 권한 적용 |
| 조선소 지도 | 시설 외곽과 도크 배치 표시, 부지 기준점·방위각 조정 | 브이월드 배경은 인증키 설정에 따름 |

## ERP–Unity 연동

| 용도 | ERP 조회 | 데이터 |
| --- | --- | --- |
| 탑재 | `/api/erection_timeline?hull=SN2040` | 블록별 형상·중량·선후행·계획일·모델 키 |
| 배치 | `/api/location_geometry`, `/api/hull_placements`, `/api/block_stock_plans` | 시설·도크 기준점과 계획일 기준 적치 |
| 이동 기록 | `/api/blocks`, `/api/moves`, `/api/telemetry` | 마지막 확인 위치, 이동 시작·확정, 시각별 좌표·하중 |
| 오프라인 | Python export_twin.py | Unity 내장 스냅샷 |

ERP API는 로그인에서 발급한 Bearer 토큰을 사용합니다. 좌표·모델 피벗·응답 형식은 [Twin 데이터 계약](../apps/twin/docs/TWIN_FORMAT.md)을 따릅니다. ERP는 생산·이동 상태의 원본이며, Unity의 탑재는 계획 기반 시뮬레이션입니다. 데모 호선과 작업 데이터는 가상입니다.
